# AI Contribution Policy

This context defines the repository's vocabulary for declaring AI-authored source content. The operational rules live in `AGENTS.md`.

## Language

**Applicable source file**:
A hand-maintained, comment-capable file containing code or executable behavior and therefore subject to the repository's declaration policy.
_Avoid_: Any file, text file

**Source-File AI Declaration**:
The required two-line comment near the beginning of an applicable source file that states its current AI-contribution level, optionally followed by a human-authored baseline.
_Avoid_: AI notice, attribution header

**Human-authored baseline**:
An optional human-authorized record of the human-written share and its actual authors when the baseline was introduced.
_Avoid_: Human detection, Git authorship

**Substantive AI contribution**:
AI-authored content that affects program logic, tests, queries, schemas, infrastructure behavior, or executable configuration rather than only formatting or whitespace.
_Avoid_: AI edit, automated change

**AI-contribution level**:
One of the three approved descriptions of how much substantive content in the resulting file was generated by any AI.
_Avoid_: AI score, authorship percentage
